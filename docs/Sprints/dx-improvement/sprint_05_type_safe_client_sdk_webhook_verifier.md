# Sprint 5 — Type-Safe Client SDK & Webhook Verifier (`@beechcms/client`)

> Generated by the Sprint Planning stage. Verified against `graphify` graph (7999 nodes / 18575 edges, rebuilt 2026-06-22) and the BeechCMS invariants in `_config/ponytail_arch.md`.

==========================================================================
SECTION 1 — WHY THIS SPRINT EXISTS FIRST
==========================================================================

This sprint delivers the **official isomorphic consumer SDK** for the BeechCMS Public API. It must be built as a foundational, self-contained leaf package *before* any frontend/example app work, for three architectural reasons:

1. **It is a pure consumer at the network boundary — never a DB participant.** The SDK lives at the outermost tier (a browser/Node/edge package that talks HTTP). It NEVER touches D1, the `ContentRepository`, or the Botanical Engine. The Botanical Invariant ("all DB access flows through `@beech/core`") is preserved *by construction*: the SDK only knows about the public HTTP contract (`/api/v1/public/:seed`), which is itself already mediated by the engine on the server. There is no D1 binding, no `apiToDb`/`dbToApi`, no Branch-ID translation in this package — those remain server-side concerns.

2. **VSA forces the crypto to move into `@beech/core` *first*.** The webhook verifier must "reuse the secure crypto logic of `@beechcms/core`" (brief requirement). **Graphify proves that logic does NOT yet live in core.** The only HMAC-SHA256 implementation in the repo is a *private* `signBody()` function inside `apps/api/src/features/automations/action-executors/webhook.executor.ts` (a Vertical Slice). A package can never import from `apps/api` — doing so is a cross-tier VSA violation and would also create a circular/inverted dependency. Therefore Step 1 of this sprint **hoists** the HMAC sign/verify primitives into `@beech/core`, refactors the existing executor to consume them (no behavioral change, no duplication), and only then lets the SDK import the verifier. This is the canonical "two slices need the same logic → move it to `@beech/core`" mandate (Ponytail rule 3).

3. **It is a stable contract surface other features will build on.** Because the SDK encodes the public query grammar (filter operators, pagination, sort) and the signature format, it must be specified surgically and frozen early so downstream example apps and docs depend on a fixed API.

**YAGNI posture:** zero new runtime dependencies, zero new HTTP framework, no codegen changes (it *consumes* the Sprint 3 `SeedRegistryTypes` output, it does not regenerate it). No retries/caching/streaming abstractions in v1.

**Public API surface (server, already shipped) — the exact contract the SDK targets:**

- Mount point (`apps/api/src/factory.ts:346-350`):
  ```
  apiPublic.use('*', publicRateLimitMiddleware())   // 1st
  apiPublic.use('*', apiKeyMiddleware())            // 2nd
  apiPublic.route('/', publicRoutes)
  app.route('/api/v1/public', apiPublic)            // base path
  ```
  Middleware order is **rate-limit → api-key → handler**. Base path is **`/api/v1/public`**.

- Routes (`apps/api/src/public/public-routes.ts`):
  - `GET  /:seed`            → list, OR single when `?id=` / `?slug=` is present (`public-read.ts`)
  - `POST /:seed/add`        → create (`public-add.ts`)
  - `PUT  /:seed/edit/:id`   → update (`public-edit.ts`)
  - `GET  /schema`           → public seed schema (slug, label, branches, policies)
  - `GET  /health`           → `{ ok: true, service: 'public-api' }`

- **Auth contract** (`apps/api/src/public/api-key-middleware.ts`): header is **`X-API-Key`** (NOT `Authorization`). Read methods (GET/HEAD/OPTIONS) validate against `PUBLIC_READ_API_KEY`; write methods against `PUBLIC_WRITE_API_KEY`. A missing server key → `403`; a wrong/absent client key → `401`.

- **List query grammar** (`apps/api/src/public/read-list.ts` + `query-builder.ts`):
  - `page` (default 1), `limit` (default 25, **hard cap 100**)
  - `all=true` → page 1, limit 100
  - `latest=<n>` → newest n by `created_at DESC` (1..100, default 10)
  - `search` → FTS
  - `orderBy` (default `created_at`), `orderDir` (`asc`|`desc`, default `desc`)
  - `fields` → comma-separated projection
  - `filter` → **URL-encoded JSON string** of shape:
    ```jsonc
    { "logic": "AND" | "OR", "where": [ { "field": string, "op": <operator>, "value"?: unknown } ] }
    ```
  - Supported operators (`PUBLIC_FILTER_OPERATORS`): `eq, neq, gt, gte, lt, lte, contains, not_contains, starts_with, ends_with, is_empty, is_not_empty, in, not_in, has_tag, has_any_tag, has_all_tags`.

- **Response shapes** (`public-read.ts`, `response-builder.ts`):
  - List: `{ data: T[], meta: { total, page, limit, returned, seed } }`
  - `latest` list: `{ data: T[], meta: { total, returned, seed } }`
  - Single: `{ data: T, meta: { seed } }`
  - **Errors: RFC 9457 Problem Details** (`problem-details.ts`), `Content-Type: application/problem+json`, body `{ type, title, status, detail, instance, errors? }`.

**Existing crypto (to be hoisted) — `apps/api/.../webhook.executor.ts:15-28`:**
- Private `signBody(body, secret)`: Web Crypto `crypto.subtle.importKey(HMAC, SHA-256)` → `crypto.subtle.sign` → returns **`sha256=<hex>`**.
- Outbound header is **`X-BeechCMS-Signature`** (note: the brief's prose says `X-Beech-Signature` — the *real* header in code is `X-BeechCMS-Signature`; the SDK MUST follow the code, not the brief prose).
- `crypto.subtle` is isomorphic (Node ≥ 20, browsers, Workers) → safe for a runtime-agnostic core util.

**`@beech/core` exports (`packages/core/src/index.ts`):** flat barrel via `export * from './*.js'`. `webhook-validation.js` exists but contains ONLY `isPrivateHost` / `PRIVATE_HOST_REGEX` — **no HMAC**. Core is ESM (`"type":"module"`), built with `tsc`, single `.` export (`./dist/index.js`). Core carries heavy deps (tiptap, katex, zod), so the SDK must NOT import the core barrel — it needs a dedicated zero-transitive-dep subpath (see Section 4).

**Sprint 3 codegen (consumed, not modified) — `packages/core/src/seed-types-generator.ts`:** `generateSeedTypes()` emits one `interface PascalCase(slug)` per seed plus a map interface **`SeedRegistryTypes`** (`{ [slug]: PascalCaseType }`). **Package precedent (`packages/widget-sdk/package.json`):** the monorepo's template for a new publishable leaf package — `"type":"module"`, `main/module/types` → `dist`, `build: tsc`, `test: vitest run`, `files:["dist"]`, version pinned to the workspace `0.6.0-preview.3`.

### 4.1 — `packages/core/src/webhook-crypto.ts`

Lift the existing algorithm verbatim, add a constant-time verify. Web Crypto only — no Node `crypto` import (keeps it isomorphic and zero-transitive-dep).

```ts
// SPDX-License-Identifier: MIT
// Copyright (c) 2024–2026 Flavio De Musso

const SIG_PREFIX = 'sha256='

function toHex(buf: ArrayBuffer): string {
  return Array.from(new Uint8Array(buf))
    .map((b) => b.toString(16).padStart(2, '0'))
    .join('')
}

async function hmacKey(secret: string): Promise<CryptoKey> {
  return crypto.subtle.importKey(
    'raw',
    new TextEncoder().encode(secret),
    { name: 'HMAC', hash: 'SHA-256' },
    false,
    ['sign'],
  )
}

/** Signs a raw request body. Returns `sha256=<hex>`. */
export async function signWebhookBody(body: string, secret: string): Promise<string> {
  const key = await hmacKey(secret)
  const sig = await crypto.subtle.sign('HMAC', key, new TextEncoder().encode(body))
  return SIG_PREFIX + toHex(sig)
}

/** Constant-time comparison of two equal-or-unequal-length hex strings. */
function timingSafeEqual(a: string, b: string): boolean {
  if (a.length !== b.length) return false
  let mismatch = 0
  for (let i = 0; i < a.length; i++) mismatch |= a.charCodeAt(i) ^ b.charCodeAt(i)
  return mismatch === 0
}

/**
 * Verifies an inbound signature against the recomputed HMAC.
 * Accepts the `sha256=` prefix on the provided signature (optional).
 */
export async function verifyWebhookSignature(
  body: string,
  signature: string | null | undefined,
  secret: string,
): Promise<boolean> {
  if (!signature || !secret) return false
  const expected = await signWebhookBody(body, secret)
  const provided = signature.startsWith(SIG_PREFIX) ? signature : SIG_PREFIX + signature
  return timingSafeEqual(expected, provided)
}
```

Refactor `webhook.executor.ts`: remove lines 15-28 (`signBody`) and replace its call site (`await signBody(body, secret)`) with `await signWebhookBody(body, secret)` imported from `@beechcms/core/webhook-crypto`. Behavior identical.

### 4.5 — `packages/client/src/query-builder.ts`

Translates the ergonomic object into the exact server query grammar from Section 2.

```ts
import type { BeechFilterOperator, ListQuery } from './types'

const OPERATORS = new Set<BeechFilterOperator>([
  'eq','neq','gt','gte','lt','lte','contains','not_contains','starts_with',
  'ends_with','is_empty','is_not_empty','in','not_in','has_tag','has_any_tag','has_all_tags',
])

/** { status:'published', price:{ gt:10 } } → { where:[{field,op,value}], logic } */
export function buildSearchParams(query: ListQuery<Record<string, unknown>> = {}): URLSearchParams {
  const params = new URLSearchParams()

  if (query.filter) {
    const where: { field: string; op: BeechFilterOperator; value?: unknown }[] = []
    for (const [field, raw] of Object.entries(query.filter)) {
      if (raw !== null && typeof raw === 'object' && !Array.isArray(raw)) {
        for (const [op, value] of Object.entries(raw)) {
          if (!OPERATORS.has(op as BeechFilterOperator)) {
            throw new TypeError(`Invalid filter operator '${op}' on field '${field}'`)
          }
          where.push({ field, op: op as BeechFilterOperator, value })
        }
      } else {
        where.push({ field, op: 'eq', value: raw }) // shorthand: eq
      }
    }
    if (where.length) {
      params.set('filter', JSON.stringify({ logic: query.logic ?? 'AND', where }))
    }
  }

  if (query.sort) {
    const [col, dir] = Object.entries(query.sort)[0] ?? []
    if (col) { params.set('orderBy', col); params.set('orderDir', dir ?? 'desc') }
  }
  if (query.search) params.set('search', query.search)
  if (query.fields?.length) params.set('fields', query.fields.join(','))
  if (typeof query.latest === 'number') params.set('latest', String(query.latest))
  if (typeof query.page === 'number') params.set('page', String(query.page))
  if (typeof query.limit === 'number') params.set('limit', String(Math.min(query.limit, 100)))

  return params
}
```

### 4.6 — `packages/client/src/http.ts`

```ts
import type { BeechClientConfig, BeechProblem, BeechResult } from './types'

export async function request<T>(
  cfg: BeechClientConfig,
  method: string,
  path: string,           // e.g. /articoli  (relative to /api/v1/public)
  opts: { params?: URLSearchParams; body?: unknown } = {},
): Promise<BeechResult<T>> {
  const doFetch = cfg.fetch ?? fetch
  const base = cfg.baseUrl.replace(/\/+$/, '')
  const qs = opts.params && [...opts.params].length ? `?${opts.params}` : ''
  const url = `${base}/api/v1/public${path}${qs}`

  let res: Response
  try {
    res = await doFetch(url, {
      method,
      headers: {
        'X-API-Key': cfg.apiKey,
        ...(opts.body !== undefined ? { 'Content-Type': 'application/json' } : {}),
      },
      body: opts.body !== undefined ? JSON.stringify(opts.body) : undefined,
    })
  } catch (e) {
    return { data: null, error: networkProblem(e) }
  }

  const ct = res.headers.get('Content-Type') ?? ''
  const payload = ct.includes('json') ? await res.json().catch(() => null) : null

  if (!res.ok) {
    return { data: null, error: (payload ?? fallbackProblem(res.status)) as BeechProblem }
  }
  return { data: payload as T, error: null }
}

function networkProblem(e: unknown): BeechProblem {
  return { type: 'about:blank', title: 'Network Error', status: 0,
    detail: e instanceof Error ? e.message : 'fetch failed' }
}
function fallbackProblem(status: number): BeechProblem {
  return { type: 'about:blank', title: 'HTTP Error', status, detail: `Request failed with status ${status}` }
}
```

### 4.7 — `packages/client/src/client.ts`

```ts
import type { BeechClientConfig, BeechResult, ListQuery, ListMeta } from './types'
import { buildSearchParams } from './query-builder'
import { request } from './http'

type Listable<TRow> = { data: TRow[]; meta: ListMeta }
type Single<TRow>   = { data: TRow;   meta: { seed: string } }

export interface ContentResource<TRow> {
  list(query?: ListQuery<TRow>): Promise<BeechResult<Listable<TRow>>>
  get(selector: { id: string } | { slug: string }): Promise<BeechResult<Single<TRow>>>
  create(input: Partial<TRow>): Promise<BeechResult<Single<TRow>>>
  update(id: string, input: Partial<TRow>): Promise<BeechResult<Single<TRow>>>
}

export interface BeechClient<TRegistry> {
  content<K extends keyof TRegistry & string>(seed: K): ContentResource<TRegistry[K]>
}

export function createBeechClient<TRegistry = Record<string, unknown>>(
  config: BeechClientConfig,
): BeechClient<TRegistry> {
  return {
    content(seed) {
      type TRow = TRegistry[typeof seed]
      const enc = encodeURIComponent(seed)
      return {
        list: (q) =>
          request<Listable<TRow>>(config, 'GET', `/${enc}`, { params: buildSearchParams(q as ListQuery<Record<string, unknown>>) }),
        get: (sel) => {
          const p = new URLSearchParams('id' in sel ? { id: sel.id } : { slug: sel.slug })
          return request<Single<TRow>>(config, 'GET', `/${enc}`, { params: p })
        },
        create: (input) => request<Single<TRow>>(config, 'POST', `/${enc}/add`, { body: input }),
        update: (id, input) =>
          request<Single<TRow>>(config, 'PUT', `/${enc}/edit/${encodeURIComponent(id)}`, { body: input }),
      }
    },
  }
}
```

SECTION 7 — OUT OF SCOPE
==========================================================================

The executing agent MUST NOT:

- Touch D1, `ContentRepository`, the Botanical Engine, or any `content_{slug}` table. The SDK is HTTP-only; **any DB access from this package is an instant VETO.**
- Import from `apps/api/**` or `apps/dashboard/**` into the SDK (VSA cross-tier violation). Shared logic goes through `@beech/core` only.
- Modify the Public API server handlers, routes, middleware, or the query grammar in `apps/api/src/public/**`. The SDK conforms to the existing contract; it does not change it.
