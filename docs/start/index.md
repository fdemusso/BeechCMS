## Getting Started

BeechCMS is built from the ground up for edge architectures:
- **Zero Cold Starts**: Deployed on Cloudflare Workers edge network.
- **Botanical Engine**: Relational schemas compiled dynamically into optimized physical D1 tables.
- **Direct-to-R2 Media**: Uploads stream directly to Cloudflare R2 storage via presigned URLs.
