# Variable: LOGIN\_PASSWORD\_MAX\_BYTES

> `const` **LOGIN\_PASSWORD\_MAX\_BYTES**: `72` = `72`

bcrypt silently truncates at 72 bytes; refusing longer input stops two passwords sharing a hash.
