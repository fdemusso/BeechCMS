# Function: slugify()

> **slugify**(`value`): `string`

Converte una stringa in uno slug URL-safe.
Limita la lunghezza a `MAX_SLUG_LENGTH` caratteri.
Never emits `_`, so a live slug can never carry `TRASHED_SLUG_INFIX`.

## Parameters

### value

`string`

## Returns

`string`
