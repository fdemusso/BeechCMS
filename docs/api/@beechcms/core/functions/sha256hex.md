# Function: sha256hex()

> **sha256hex**(`value`): `Promise`&lt;`string`&gt;

Computes an un-salted SHA-256 hex digest of a string value.
Used for basic digest operations.

## Parameters

### value

`string`

The raw string value to hash.

## Returns

`Promise`&lt;`string`&gt;

A Promise resolving to a 64-character hex string.
