# Function: extensionFromUrl()

> **extensionFromUrl**(`url`): `string` \| `null`

Extracts a lowercase file extension from a URL string or query parameters.

## Parameters

### url

`string`

The URL string to parse.

## Returns

`string` \| `null`

The extracted extension, or null if none was found.
