# Function: isValidColumn()

> **isValidColumn**(`seed`, `col`): `boolean`

Determines whether a column is valid for a given Seed (either system column or branch alias).

## Parameters

### seed

[`Seed`](../interfaces/Seed.md)

The seed definition.

### col

`string`

The column name to check.

## Returns

`boolean`

True if the column is valid, false otherwise.
