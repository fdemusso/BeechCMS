# Reference

Technical contracts, specifications, and SDK references for the BeechCMS ecosystem.

## Official Contracts & SDKs

- **REST API Reference**: Edge endpoints for authentication, content, media, and automations.
- **Client SDK (`@beechcms/client`)**: Typed TypeScript client for query construction and caching.
- **Forms SDK (`@beechcms/forms-react`)**: React form bindings and validation hooks.
- **Search Client (`@beechcms/search-client`)**: Vector similarity and client-side search cache.
- **CLI Reference (`@beechcms/cli`)**: Command flags, options, and exit codes.
