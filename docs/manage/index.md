# Manage

Manage operational workflows, content authoring, assets, and security in the BeechCMS Dashboard.

## Dashboard & Operations

- **Content Editor**: Visual layout builder and rich text composition with BlockNote.
- **CodeMirror JSON Editor**: Structured JSON field editing with real-time schema validation.
- **Media Asset Library**: Direct-to-R2 image and asset management with presigned upload workflows.
- **Access Control & Roles**: JWT token lifecycle with short-lived tokens and refresh rotation.
- **Hardening & Rate Limiting**: Dual-key token bucket protection and security audits.
